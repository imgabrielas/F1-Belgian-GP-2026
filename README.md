# F1 Enthusiast

A collection of Formula 1 data projects built around the [FastF1](https://github.com/theOehrly/Fast-F1) API.

## Projects

| Project | Description |
| --- | --- |
| [[Belgian GP Winner Prediction]] | Machine learning models that predict the Belgian GP race winner from qualifying data. |
| [[data-analysis]] | Exploratory data analysis and interactive visualisations of the F1 season, with a race-weekend deep dive into Monaco 2026. |
